# Mi Sagrado Corazón

La comunidad de fe que enciende el mundo.

App móvil católica para la comunidad hispana (EEUU + México). Tres pilares:
ritual diario personal con vela virtual, misa dominical en vivo e impacto mensual votado (20% de la facturación a la causa ganadora).
