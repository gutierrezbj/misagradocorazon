# Requisitos de entrega

El equipo del fundador asumirá el mantenimiento y la evolución tras la entrega.

1. Código completo en este repositorio, con commits frecuentes y descriptivos.
2. Ejecutable fuera de la plataforma del constructor: exportable, con instrucciones de instalación y ejecución local.
3. Todas las cuentas de servicios (stores, Firebase, YouTube, base de datos, hosting) a nombre del fundador.
4. README técnico: stack y versiones, estructura de carpetas, .env.example sin secretos, cómo levantar el entorno, cómo generar builds iOS/Android y cómo desplegar el backend y el panel admin.
5. Documentación del modelo de datos y de los endpoints de la API.
6. Lista de dependencias y servicios de terceros con su propósito.
7. Lista de lo que queda simulado o pendiente (pagos reales, Apple Sign-In, etc.).
8. TypeScript, estructura modular por pilar: ritual diario, misa, causas, admin.
9. Ningún secreto, clave o token en el repositorio.
